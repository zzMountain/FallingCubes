# Falling Cubes

Учебное задание для Unity 6: над платформой постоянно появляются кубы, созданные через пул объектов.
После первого столкновения с любой отмеченной платформой куб один раз меняет цвет, получает случайный срок
жизни от 2 до 5 секунд и затем возвращается в пул.

## Состав

- `FallingCube` хранит состояние куба, обрабатывает столкновения и управляет временем возврата в пул.
- `FallingCubeView` отвечает только за отображение исходного и контактного цвета.
- `FallingCubePool` создаёт, выдаёт и принимает экземпляры кубов.
- `FallingCubeSpawner` периодически запрашивает кубы у пула и размещает их в случайных позициях.
- `FallingCubeSurface` отмечает платформы, столкновение с которыми запускает эффект.
- `FallingCubeReturnZone` отмечает нижнюю trigger-зону для возврата улетевших кубов.

## Настройка в Unity

1. Используйте Unity 6. В коде применяется `Rigidbody.linearVelocity`.
2. Создайте prefab куба с `Collider`, `Renderer`, `Rigidbody`, `FallingCube` и `FallingCubeView`.
3. Сохраните корневой объект prefab неактивным, чтобы пул передавал зависимости до первой активации.
4. Добавьте `FallingCubePool` и `FallingCubeSpawner` на один объект и назначьте prefab в поле `_cubeTemplate`.
5. Добавьте `FallingCubeSurface` на основную и наклонные платформы.
6. Добавьте `FallingCubeReturnZone` на нижний `Collider` с включённым `Is Trigger`.
7. Разместите платформы, камеру и освещение вручную в сцене. Скрипты не создают окружение.

Рекомендуемые настройки `Rigidbody` prefab: `Interpolate` и `Continuous Dynamic`.
