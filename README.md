# Falling Cubes

## Состав

- `Cube` хранит состояние первого контакта, цвета и оставшееся время жизни, а затем вызывает
  `LifetimeExpired`, не зная о пуле.
- `CubePool` создаёт, активирует и принимает экземпляры, подписывается на событие и защищает пул от
  повторного `Release`.
- `CubeSpawner` периодически запрашивает у пула кубы в случайных позициях над платформой.
- `Platform` отмечает основную и дополнительные наклонные платформы.
- `CubeReturnZone` возвращает улетевшие кубы через явно назначенный `CubePool`.
